1.1. Título del reto : Desarrollo e implantación de una página web para un pequeño negocio con infraestructura de servidor y base de datos

Este proyecto forma parte del Proyecto Intermodular de 2.º de ASIR.

1.2. Contexto

El proyecto se plantea para un pequeño restaurante que actualmente no dispone de una página web propia. En esta situación, los clientes pueden realizar sus reservas principalmente mediante llamadas telefónicas.

Este sistema puede presentar algunas dificultades, como la recepción de llamadas fuera del horario de atención del restaurante. Además, algunos clientes pueden preferir no realizar una llamada telefónica para efectuar una reserva.

1.3. Problemática o necesidad

El restaurante presenta principalmente dos necesidades. Por un lado, la gestión de las reservas depende de las llamadas telefónicas, lo que puede dificultar que los clientes puedan reservar fuera del horario de atención o para aquellas personas que prefieren no realizar llamadas.

Por otro lado, el restaurante tiene una visibilidad limitada al no disponer de una página web propia. Una presencia web permitiría mostrar información sobre el negocio, su forma de trabajar y sus servicios, facilitando que nuevos clientes conozcan el restaurante y que posibles trabajadores puedan obtener información sobre él.

1.4. Objetivos

Objetivo general

Desarrollar e implantar una página web para un pequeño restaurante que mejore su presencia y visibilidad en Internet y facilite la gestión de las reservas de sus clientes.

Objetivos específicos

  • Crear una página web que permita al restaurante mostrar información sobre su actividad, servicios y forma de trabajo, mejorando su presencia y visibilidad en Internet.

  • Implementar un sistema que permita a los clientes consultar y realizar reservas de forma sencilla, evitando que tengan que depender exclusivamente de una llamada telefónica.

  • Diseñar e implantar una infraestructura de servidor que permita alojar la página web y gestionar de forma adecuada los datos necesarios para el funcionamiento del sistema de reservas.

  • Facilitar el acceso de los clientes a la información del restaurante y mejorar su experiencia a la hora de conocer sus servicios y realizar una reserva.

1.5. Interesados

Interesado Relación con el proyecto Necesidad principal
Dueño del restaurante Principal responsable y usuario de la solución Mejorar la visibilidad del restaurante y gestionar las reservas
Clientes Usuarios de la página web y del sistema de reservas Consultar información y realizar reservas de forma sencilla
Posibles inversores Personas interesadas en la evolución y expansión del negocio Conocer la presencia y funcionamiento del restaurante

El proyecto se desarrollará teniendo en cuenta las necesidades de los diferentes interesados identificados.
